# PPL — дневник тренировок

Офлайн-приложение (PWA) для программы Push / Pull / Legs. Работает на iPhone без интернета, все данные хранятся на телефоне.

## Установка на iPhone (один раз)

Приложение нужно один раз выложить по HTTPS-адресу. Проще всего через GitHub Pages: это бесплатно и без командной строки.

1. Зарегистрируйся на [github.com](https://github.com).
2. Нажми **New repository**, имя например `ppl`, тип **Public**, затем **Create repository**.
3. На странице репозитория нажми ссылку **uploading an existing file** и перетащи туда:
   `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest` и папку `icons` целиком.
   Затем нажми **Commit changes**.
4. Открой **Settings → Pages**. В разделе *Build and deployment* выбери *Deploy from a branch*, ветку `main`, папку `/ (root)` и нажми **Save**.
   Через 1–2 минуты появится адрес вида `https://ИМЯ.github.io/ppl/`.
5. На iPhone открой этот адрес **в Safari**, нажми **Поделиться → На экран «Домой»**.
6. Один раз запусти приложение с иконки, пока есть интернет. После этого оно работает полностью офлайн.

> В репозитории лежит только код. Твои тренировки туда не попадают: они хранятся на телефоне.

## Важно знать

- **Резервные копии.** Если удалить иконку приложения, данные удалятся вместе с ней. Время от времени нажимай
  «Программа → Сохранить резервную копию» и сохраняй файл в «Файлы» или iCloud. Восстановить данные можно там же.
- **Safari и установленное приложение хранят данные раздельно.** Записывай тренировки в приложении с иконки.
- **Таймер отдыха** беззвучный: когда отдых закончился, полоска таймера становится зелёной с надписью «Пора к подходу».
  Время считается правильно, даже если свернуть приложение. Пока идёт тренировка, экран телефона не гаснет.

## Как обновить приложение

1. Измени файлы.
2. В `sw.js` увеличь `VERSION` (например, `'v1'` → `'v2'`). Без этого телефон не узнает о новой версии.
3. Загрузи изменённые файлы в репозиторий так же, как в шаге 3.
4. При следующем запуске с интернетом приложение покажет «Доступна новая версия → Обновить».
